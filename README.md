# Ness TIKTAK
TIKTAK - Attendance to Timesheet | PowerShell Tool by AlonDet

מדריך למילוי TIKTAK 

1. הורד את קובץ הנוכחות משעון הנוכחות (אפשר לתקן אותו לבד).
2. הפעל את הסקריפט TIKTAK.
3. בחר קודם את קובץ הנוכחות ולאחר מכן את קובץ ה-Timesheet.
4. בסיום ייפתח קובץ ה-Excel המוכן.
5. בדוק את הימים שסומנו כ-WARNING או NO ATTENDANCE.
6. במידת הצורך השלם ידנית חופשה, מחלה או שעות חסרות. 
7. שמור את קובץ ה-Excel לאחר התיקונים.
8. חזור לחלון TIKTAK ולחץ R כדי לבצע בדיקה חוזרת.
9. ניתן לתקן ולבצע Recheck שוב עד שכל הימים מלאים.
10. כשהמערכת מודיעה שאין ימים חסרים, בצע בדיקה סופית והעלה את הקובץ.

הערה: הסקריפט ממלא אוטומטית את נתוני הנוכחות כ”יום עבודה רגיל”. 
חופשה,מחלה או תיקונים מיוחדים יש להשלים ידנית ולאחר מכן לבצע Recheck(אישורי מחלה צריך לעלות ידנית לבד).
בנוסף צריך לצאת מהסקריפט בעזרת Q ולא על ה-X.
